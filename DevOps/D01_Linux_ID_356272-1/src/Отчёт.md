## Часть 1. Установка ОС
- Скачиваем установочный образ `https://releases.ubuntu.com/24.04/`
- Скачиваем программу для виртуализации `VirtualBox` (файл вида `ubuntu-24.04.X-live-server-amd64.iso`) `https://www.virtualbox.org/wiki/Downloads`
- Создание виртуальной машины
    - Запускаем `VirtualBox`
    - Нажимаем `Создать`
    - Задаем имя вирутальной машины
    - Выбираем установленный образ ICO
    - Задаём имя пользователя и пароль
    - Задаём количество оперативной памяти и процессоров
    - Создаём новый виртуальный диск и выделяем ему размер места
    - Проверяем информацию о созданной виртуальной машине, при готовности нажимаем Готово
- Создание ОС
    - Запускаем созданную вирутальную машину
    - Ждём всех обновлений
    - Вводим логин и пароль
    - Узнаем версию Ubuntu через команду `cat /etc/issue`

## Часть 8. Установка и базовая настройка сервиса SSHD
- Устанавливаем пакет `OpenSSH Server`, содержащий демон `SSHd`, используя команду:

        sudo apt install openssh-server -y

- Добавляем автостарт службы при загрузке системы через команду:

        sudo systemctl enable ssh

- Для перенастраивания службы `SSHd` на порт `2022` редактируем конфигурационный файл `SSH` через команду:

        sudo nano /etc/ssh/sshd_config

- В редакторе меняем строку `#Port 22` на `Port 2022` (именно без `#`)

- Показываем наличие процесса `sshd`, используя команду:

        ps -С sshd
    
![8.1.png](screens/8.1.png)
> `ps` - команда для отображения информации о запущенных процессах в системе.

Ключи команды `ps`:
1. `-A, -e, (a)` - показать все процессы
2. `-a` - показать все процессы, кроме фоновых
3. `-d, (g)` - показать все процессы, включая фоновые, кроме процессов сессий
4. `-N` - показать все процессы, кроме указанных
5. `-C` - показать процессы по имени команды
6. `-G` - показать процессы по ID группы
7. `-p, (p)` - показать процессы PID
8. `--ppid` - показать процессы по PID родительского процесса
9. `-s` - показать процессы по ID сессии
10. `-t, (t)` - показать процессы по tty
11. `-u, (U)` - показать процессы пользователя

- Перезагружаем систему с помощью команды:

        sudo reboot

- Перед вводом последующей команды, установим `net-tools`:

        sudo apt install net-tools

- Вводим команду:

        netstat -tan

![8.2.png](screens/8.2.png)
> `-t` - выводит только TCP-соединения, `-a` - отображает все активыне соединения, `-n` - не преобразовывать IP-aдреса в доменные имена, а номера портов в сервисные имена

Столбцы вывода команды `netstat -tan`:
1. `Proto` - транспортный протокол (tcp, tcp6 и т.д.)
2. `Recv-Q` (Receive Queue) - Количество полученных, но ещё не прочитанных приложением байт данных, находящихся в сетевом буфере (`0` - нет данных в очереди, `> 0` - приложение не успевает обрабатывать полученные данные)
3. `Send-Q` (Send Queue) - количество отправленных, но ещё не подтверждённых удалённой стороной байт данных (`0` - все данные подтверждены, `> 0` - удаленная сторона не подтверждает получение данных)
4. `Local Address` - адрес и порт на моей машине, с которого установлено соединение или который слушает сервер (`0.0.0.0:<порт>` - сервер слушает на всех сетевых интерфейсах)
5. `Foreign Address` - адрес и порт удаленной машины, с которой установлено соединение (`0.0.0.0:*` - сервер слушает, ожидая подключения с любого адреса)
6. `State` - текущее состояние TCP-соединения

    - Количество авторизованных пользователей (... user): `1`
    - Средняя загрузка системы (load average: ...): `0.02, 0.04, 0.02` (за последнюю 1 минуту, за последние 5 минут, за последние 15 минут соответственно)
    - Общее количество процессов (Tasks: ... total): `92`
    - Загрузка CPU (%Cpu(s): ... us, ... sy): us + sy = 0.0 + 0.3 = `0.3`
    - Загрузка памяти (MiB Mem: ... total, ... used): used / total * 100% = `~17,5%`

    - PID процесса, занимающего больше всего процессорного времени (PID c max %CPU): `9`

## Часть 15. Использование планировщика заданий CRON
- Редактируем файл crontab через команду:

        crontab -e

    выбираем текстовый редактор из предложенных (например, nano)
- В открывшемся редакторе добавляем в конец строку (полный путь к команде uptime можно получить через команду `which uptime`)

        */2 * * * * /usr/bin/uptime >> /tmp/uptime.log 2>&1

- Находим в системных журналах строчки о выполнении через команду:

        sudo grep -a "uptime" /var/log/syslog | tail -10

![15.1.png](screens/15.1.png)
> Строки о выполнении в системных журналах

- Выводим список текущих заданий для `CRON` через команду:

        crontab -l

![15.2.png](screens/15.2.png)
> Список текущих заданий для `CRON`

- Удаляем все задания из планировщика заданий с помощью команды

        crontab -r -i

> `-i` запрашивает подтверждение перед удалением
- Запросим список текущих заданий для `CRON` с помощью команды:

        crontab -l

![15.3.png](screens/15.3.png)
> Список пуст (все задачи очищены)
